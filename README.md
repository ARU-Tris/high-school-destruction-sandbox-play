# High School Destruction Sandbox

**[Play in your browser](https://aru-tris.github.io/high-school-destruction-sandbox-play/)** · **[Choose a high school](https://aru-tris.github.io/high-school-destruction-sandbox-play/?schools=1)**

No installation or GitHub login is required. Use a modern browser with WebGL2.

1. Bomb
2. Laser
3. Missile
4. Lightning
5. Black hole
6. Orbital Strike Cannon

Click or tap to use a weapon. Right-drag rotates the camera; the wheel zooms. Undo and reset restore the campus. Touch uses one finger for weapons and two fingers for the camera.

This repository contains the generated playable site and its Pages workflow. The source project is maintained separately. The page updates when a new site build is pushed.

School names, addresses and locations: 한국교육시설안전원 · 공공데이터포털. Geographic data: © OpenStreetMap contributors, ODbL 1.0. Game structures and physics are stylized estimates. See [data sources](site/data/SOURCES.md) and [third-party notices](site/THIRD_PARTY_NOTICES.md).
